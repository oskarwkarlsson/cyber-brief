Xen Orchestra empty-cookie login bypass exploited to take over virtualization hosts

Vates published VSA-2026-062 today and says it is actively exploited. Sending the cookie authenticationToken=j:{} makes Xen Orchestra's REST layer look up "any" token and log the attacker in as that token's owner, giving admin rights; from there the attacker can run code on managed pools and take over XCP-ng nodes as root. No CVE or CVSS yet. Fixed in Xen Orchestra 6.9.1 (stable) and 6.10.0 (latest). Vates lists attacker infrastructure (91.211.251.112 and a Tor onion), says there is no log of the unauthenticated access, and gives host checks: a VM named pivot2, VMs with hvm_serial: file, and /etc/cron.d/zz-ustar* or /.ustar* files. Takeaway: patch now, take XO off the internet, block the IOCs, and rotate all Vates secrets if compromised.

"worse_query" iOS sandbox escape is public; Binance warns wallet secrets are at risk

Researcher forcequitOS (credited with 0xjohnny) published worse_query on Sunday, a proof of concept that lets an app with an App Group container read other apps' data containers on iOS 26.0 to 26.7.2 and 27.2, plus some system folders on iOS 27. Binance warned today that malicious apps could use it to read seed phrases, private keys and logins, called it an iOS-level issue not unique to Binance, and reported no confirmed thefts. A third-party file manager built on it already installs via AltStore and SideStore sideloading. Apple's iOS 27.2.1 and 26.7.3 notes do not mention it, so a fix is unconfirmed, and nobody has said whether an App Store app could use it. Takeaway: remove sideloaded or manually signed apps and keep high-value secrets off phones that run them.

Check Point names CopperDragon, a likely supplier of the Sparrow toolset to China-nexus groups

After a year-long investigation, Check Point links three clusters hitting telecoms, governments, militaries and research bodies to one entity it calls CopperDragon, which it assesses may build and supply the Sparrow malware framework used by FamousSparrow, Earth Estries, TropicTrooper and UAT-9244. SilentDelivery compromises government, shipping and IT sites and swaps the page for a fake Chrome certificate error pushing a "Certificate Fix" installer (new SquadC backdoor), with telemetry in the Czech Republic, Germany, France, Taiwan, Hong Kong and others. OceanGate starts on internet-facing Linux servers, uses trojanized SSH and SSHD to harvest logins and a Reptile-based rootkit. DarkWire hits at least three Latin American telecoms with new CopperDoor and DNS-tunnelling CopperDNS backdoors. Takeaway: any "install this certificate" prompt on a real site is an attack; IOCs are in the report.

AhsayCBS intrusions went beyond crypto mining to backup credentials and a host-locked implant

Huntress analysed three AhsayCBS backup servers in one environment breached 8 to 11 October through the CVE-2026-105133 and CVE-2026-105134 chain (auth bypass into unauthenticated code execution as SYSTEM), exploited before Ahsay's mid-October hotfixes. The operator left five JSP web shell families (one hides payloads in PNG pixel data), two XMRig miners, GOST and Chisel tunnels, AnyDesk, Atera and Splashtop, and a Python implant that only runs on the machine it was staged for, then loads an in-memory DLL calling creepexplosiondarknight[.]com. On a related Veeam server Huntress saw a command consistent with NetExec's Veeam credential-theft module. Takeaway: the hotfix (10.3.4.45 or 9.15.2.70) does not remove planted files, so hunt patched Ahsay servers too and rotate credentials stored in backup software.
