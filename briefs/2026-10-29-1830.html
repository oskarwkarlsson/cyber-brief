Vulns

Linux kernel CVE-2026-98432 (CVSS 9.8): remote root via a TCP handshake race, and Ubuntu and RHEL have no fixed kernel yet

A use-after-free in IPv4 TCP connection setup (IP options handed to the child socket without copying) dates back to Linux 4.4. Anthropic says its model wrote an exploit giving an unauthenticated remote attacker root on servers with a multipath TCP listener; this appears to be the zero-click Linux chain from its Oct 27 post. Upstream fixed it Oct 5. Debian, Oracle Linux, SUSE and Amazon Linux have shipped fixed packages for at least some kernels; Ubuntu lists it High / 9.8 with kernels still vulnerable or in progress, and Red Hat has deferred its fix with no date. Vendor scores vary (5.9 to 8.1 at Red Hat, Amazon, Oracle, SUSE). No exploitation in the wild reported. IPv6 is not affected.

Telegram for Android: answering a voice call could let an attacker run code on the phone

Security startup NebuSec disclosed today that a malformed MediaState call message could trigger a memory access bug in versions 8.6.2 through 12.10.3 (March 2022 to September 2026); the attacker only needed an ordinary account. Fixed in 12.10.4 (late September). No CVE yet, no known in-the-wild use, and iOS, desktop and group calls are not shown to be affected. Update and check the version at the bottom of Settings. Reported via The Hacker News, which matched the flaw to Telegram's published source; NebuSec's own write-up was not checked here.

Vulns

Veeam and Juniper patch critical flaws: cross-tenant RCE in Veeam Backup for Microsoft 365, unauthenticated command execution in Juniper Session Smart Router

Veeam fixed nine flaws, including a critical cross-tenant config read/write leading to remote code execution in Backup for Microsoft 365 and a critical unauthenticated authorization bypass in Backup & Replication, plus REST API auth bypass and MFA bypass bugs. Juniper fixed 18 in Session Smart Router and Conductor, two critical (unauthenticated command execution, privilege escalation). Neither vendor reports exploitation, but backup servers are a favourite ransomware target, so patch soon.

Cyberattack forces Belgium's finance ministry to take the MyMinfin tax portal offline before an Oct 31 deadline

FPS Finance says it is investigating the attack and suspended access as a precaution; it sees no sign of data theft so far. Affected taxpayers will get extra time. No attacker or entry point has been named. Earlier this month Belgian authorities took government sites offline over the PHP2Shell flaws, but no link to today's attack has been stated.
