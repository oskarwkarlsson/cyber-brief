A suspected North Korean crew has a 216-host PHP2Shell target list covering the UAE, EU and US, and a stray AGENTS.md in Downloads can hijack AI coding agents

Suspected DPRK operators are quietly scanning 216 unpatched PHP hosts for PHP2Shell

CYFIRMA, watching a closed Korean-language I2P channel, says the operators finished a filtered list of 216 hosts that still look unpatched or only partly mitigated for CVE-2026-109618 and CVE-2026-109619, and are running low-and-slow checks from 21 compromised nodes that rotate at the first sign of blocking. Targets span government, banks, online transaction platforms, logistics, aviation and manufacturing in the US, Japan, South Korea, Southeast Asia, Australia, Taiwan, India, the UAE, Saudi Arabia and the EU. CYFIRMA rates the DPRK link high confidence but the Lazarus link only moderate, with no malware or infrastructure overlap and no named victims or launch date yet. Takeaway: patch PHP to 8.5.12, 8.4.27, 8.3.36 or 8.2.35 or newer, restart workers, and hunt back to Oct 17.

Malicious AGENTS.md in the Downloads folder steered AI coding agents into installing a rogue npm package

Forever Security found an AGENTS.md instruction file in a customer's ~/Downloads that made a coding agent try to install the malicious npm package function-color. Because browsers like Chrome, Edge and Firefox save to Downloads without asking, a web page can drop such a file, and an agent started in that folder will follow it. The researchers got calculator-launching code to run through OpenAI Codex in about 90% of tests, and a malicious CLAUDE.md redirected Claude Code's API traffic to leak its OAuth token and return code-running tool calls in about half of tests. There is no vendor patch; the fix is behavioural. Never launch Codex, Claude Code or Cursor CLI from Downloads or your home folder, and review unfamiliar instruction files.
