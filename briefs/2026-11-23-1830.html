Azure API Management Classic flaw exploited to target stored secrets

Norway's National Security Authority (NSM) says an unidentified actor exploited a vulnerability in Microsoft's Azure API Management (APIM) to target access tokens, secrets and named values, and that Equinor and Skagerak Energi, whose incidents were reported last week, are among those affected, along with organisations in several sectors in Norway and abroad. A Microsoft customer notice shared on Reddit (not public) says Microsoft found the issue on Nov 18, closed the access path on Nov 19, and that secrets in APIM Classic instances could have been accessed before then, including named values, identity provider client secrets, subscription keys and management API tokens. Classic tiers not following Microsoft's security guidance are affected; v2 tiers are not. Microsoft has not commented publicly or said how many customers were exposed. NSM advises treating APIM secrets and named values as compromised and rotating them, and checking what those credentials can reach.

N-able patches critical Mail Assure SSRF, CVE-2026-134624

While investigating last week's attack on its Mail Assure and SpamExperts hosted cloud, N-able found and patched an SSRF flaw (CVSS 9.3): the LDAP synchronisation connection check for relays did not restrict its destination, so a sufficiently privileged API user could make the server probe internal hosts and ports and send crafted data to internal services. Fixed in Mail Assure/SpamExperts version 20261121.1943. N-able restored the dashboard and APIs on Nov 21, says exploitation was confined to one N-able-hosted server, and promises a root cause analysis within two weeks. It is not stated whether this flaw was the attackers' way in.

Austrian Foreign Ministry website breached

Austria's Foreign Ministry says hackers breached a website run by an external provider between Nov 12 and 13 and accessed names and official contact details of staff in Vienna and at diplomatic missions abroad. No public personal data was hit, the breach is contained, and the ministry has not attributed it or said whether data was stolen. Context: Vienna attributed a 2019 to 2020 ministry intrusion to Russia in July 2026, and relations with Moscow have worsened. Expect spear-phishing against listed diplomats.
