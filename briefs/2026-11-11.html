Vulns

Exploited Outlook zero-day CVE-2026-124194 leads a record-size Patch Tuesday

Microsoft marks the Outlook spoofing flaw (CVSS 6.5) as exploited: a crafted message file opened in Outlook connects to an attacker-controlled location without the usual external-content warning, which can leak authentication data usable to impersonate the user. Microsoft credits Benoît Sevens, who found it using Anthropic's Claude, per The Record. CISA added it to KEV with a 24 Nov deadline and JPCERT issued an alert. Counts differ: BleepingComputer says 1,235 fixes (66 Critical), The Record 1,093 with 63 Critical; it is the only exploited bug. Takeaway: ship the Outlook update first and block outbound SMB/NTLM to the internet.

Xen Orchestra login bypass and Barracuda ESG root chain are both under attack

Vates' VSA-2026-062 says an empty authenticationToken cookie logs attackers into Xen Orchestra as an admin, letting them run code on pools and take over XCP-ng hosts as root; fixed in 6.9.1 and 6.10.0, no CVE yet, with IOCs (a VM named pivot2, /etc/cron.d/zz-ustar* files). Separately Barracuda says ESG flaws CVE-2026-116606 and CVE-2026-111560 are exploited for root against a small number of organizations; CISA set a 13 Nov deadline and ordered agencies to hunt for compromise. Takeaway: patch both, pull admin interfaces off the internet and check for the listed artifacts.

AI/Cloud

Railway breach grows to up to 100,000 workspaces' secrets and $740,000 of AI fraud

Railway's incident report says attackers escaped build isolation on 20 October through an unknown flaw, stole internal source code, then abused a misconfigured trust relationship to get keys that decrypt customer environment variables for at most 1.85% of workspaces (about 100,000, a ceiling, not a confirmed count). They hunted AI provider keys and ran up about $740,000 in AI charges, which Railway says it will cover where providers do not refund. Fireworks AI also disclosed a second breach this week via a cloud provider. Takeaway: if you deployed on Railway, rotate every secret, starting with AI API keys.

Vectors

Git 2.56.1 fixes a flaw that runs attacker code on recursive clone

CVE-2026-111760 is an integer truncation in Git's index handling: an extremely long path passes the safety check but is written to disk under a shorter name an attacker can set to .git, swapping a fresh submodule's .git file for a symlink to malicious hooks. Fixes are in 2.56.1 and backports 2.50.2 through 2.55.1, alongside five other Git CVEs; GitHub has patched github.com and lists fixed Enterprise Server builds, while Git for Windows lagged as of Tuesday evening. Takeaway: update Git everywhere, including tools that bundle it, and avoid --recurse-submodules on untrusted repos until then.
