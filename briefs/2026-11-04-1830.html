NIKKE PC launcher scripts were poisoned on the publisher's own CDN

Level Infinite says the PC launcher's script files for Goddess of Victory: NIKKE (over 45 million downloads) were tampered with, and shipped a fix on November 4 at about 02:30 (UTC+9). Researcher MotherSphere says four JavaScript files on the official CDN were modified on September 27 to pull code from insightjs[.]com and insightjs[.]org, which loaded a LuaJIT payload installing a remote-access agent called K2F (commands, file theft, screenshots, browser data). BleepingComputer confirmed the obfuscated loader in two files and found wallet-stealing code (MetaMask, Phantom, Coinbase Wallet) in a related DLL, but it is unknown whether that DLL was deployed. Takeaway: anyone who ran the PC launcher since late September should treat the machine as compromised, look for platform_experience_helper.dll, and move crypto from browser wallets.

APT download-retry flaw lets a mirror or proxy swap packages and run code as root

Debian, Ubuntu and the APT developers published advisories on November 4 for CVE-2026-109518: an attacker who can alter HTTP traffic between APT and the package server (a malicious mirror or proxy) can use redirects and temporary errors to make APT retry and accept a substituted package, whose code runs as root at install. Retries are on by default from Debian 12 and Ubuntu 22.04; older releases are exposed if Acquire::Retries was turned on. Debian has fixed builds (bookworm 2.6.2, trixie 3.0.4, sid 3.3.6); Ubuntu rates it high (CVSS 4.0 7.7) and was still rolling out builds. No exploitation reported. Takeaway: patch APT on every Debian and Ubuntu host and image, and be wary of untrusted mirrors and proxies until you do.

Wiper attack destroys VPS, cloud storage and Kubernetes data at Russia's Beget

Beget, one of Russia's largest registrars and hosts, says attackers got into its infrastructure management systems overnight on Sunday and ran scripts to erase data. VPS, cloud storage and Kubernetes data were wiped and all binary backups of virtual servers were lost; file-level backups survived. More than 1,000 servers need manual checks, and sites including a city administration and the Chestny Znak product labelling system were disrupted. No one has claimed it. Takeaway: a reminder that management-plane access plus backups on the same control plane can mean total loss; keep offline or separately administered backups.

Google Calendar invites lead to a live reverse proxy that defeats every MFA prompt

Material Security's Operation CloudFire has harvested live Google sessions from corporate users since mid-August. Invites, often from organisations the victim already knows, use Google's own /url redirector, share.google or Drive links, so link scoring sees trusted domains. A reverse proxy (the Nyasher framework) relays passwords, SMS and authenticator codes, number matching and phone recovery in real time. Material says it has taken down hundreds of domains. Takeaway: only phishing-resistant MFA (passkeys or security keys) stops this; flag external calendar invites with sign-in links.
