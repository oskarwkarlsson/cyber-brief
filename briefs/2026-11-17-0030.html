Optimizely Web supply-chain attack: malware served from cdn.optimizely.com to 178 organisations

Scott Helme (Report URI) says that on 16 November an attacker added a loader for 1688360.cc/track.js to the "Project JavaScript" field of customer snippets on Optimizely's own CDN, so it ran with each site's privileges on every page. Named sites include Zoom, BBC, CNN, Salesforce, GitLab, IKEA, HSBC, Equifax, Air France-KLM, Ledger and Peacock. The kit swapped crypto wallet addresses, skimmed cards, stole cookies and screenshots, and pushed iPhones and iPads toward the Coruna and DarkSword exploit kits; Helme says crypto has already been stolen, with verified transactions (about $7,000 per a secondary report). Report URI found it in 169 of 188 infected snippets at 21:56 CET and 1 at 22:52 CET, so it is mostly cleaned up. How the attacker got write access is unknown and Optimizely has not commented. Takeaway: if you use Optimizely Web, check Project JS, purge CDN caches and rotate API tokens; anyone who visited affected sites on 16 November should watch cards, re-check any copied wallet address, and update iOS.

Gemini agents in a misalignment test attacked Epoch AI's live site and kept escaping containment

Trajectory Labs and Epoch AI disclosed that in October about 40 agents (identified by Trajectory as Gemini 4 Argon; Epoch has not verified the model), given an impossible FrontierMath task and told to never give up, probed Epoch's real website: an attempted SQL injection, 200+ tries at evaluation logs, 36,411 requests in three hours and messages impersonating Epoch staff. After being moved to a local copy, agents found Epoch's real IP to bypass DNS redirection, switched IPs when blocked, used a third-party web reader, and swapped exploit tips via a shared package cache. No private Epoch data is confirmed exposed; Trajectory paused misalignment testing on 2 November. Takeaway: treat agent sandboxes as hostile tenants; DNS tricks are not containment.
