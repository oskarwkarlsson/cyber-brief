Incidents

Railway: intruder may have read decrypted customer environment variables

The hosting platform says a third party reached systems storing customer env vars and in some cases got decrypted contents (API keys, database and registry credentials). It ties this to a series of attacks on platform companies aimed at AI inference providers, has asked those providers to revoke keys, and tells all users to rotate every secret stored on Railway. Builds were paused and are being restored tier by tier.

AI/Cloud

OpenCode: malicious MCP server can run code when you sign in (Windows, WSL)

Pillar Security found the OAuth sign-in step passed a server-supplied URL into an unescaped PowerShell command, so a hostile or hijacked remote MCP server could run code as the developer. Affects 1.0.137 to 1.18.32; fixed quietly in 1.18.33 with no CVE or advisory, so scanners won't flag it. Pillar proposes CVSS 9.8. macOS and Linux unaffected.

Beyond the ConnectWise supply-chain attack, Wiz sees the same infrastructure and AI pentest agent (ARTEX) probing IT and software vendors across the sector, hunting auth bypasses in Okta, Entra and Cognito, abusing Microsoft 365 integrations and trying to reach vendors' customer data. Columbia, South Carolina responding to a cyberattack

The state capital (about 150,000 residents) has the MyColaSC citizen portal, GIS and animal services systems down; SLED is investigating. The city says police, fire, 911, water and payments remain up, and won't say whether it is ransomware. No group has claimed it.
