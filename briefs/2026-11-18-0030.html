Java4Shell (CVE-2026-114938): OpenJDK memory corruption now confirmed and patched, PoC public

Calif disclosed the flaw on Tuesday: a memory-corruption bug in OpenJDK's AVX-512 hardware-accelerated Base64 decoder, triggered by as little as 64 "A" characters and an "=", affecting OpenJDK 17.0.6 and later and builds made from it (Oracle Java SE, Corretto, Temurin, Microsoft, Zulu, Red Hat). Calif says it achieved unauthenticated RCE on default installs of Keycloak, Jira, Confluence, Artifactory, Jenkins and PingFederate, and authenticated RCE on Kafka, Solr, Elasticsearch, Gerrit and Spinnaker; it needs an app-specific path to feed Base64 to the decoder and an x86-64 CPU with AVX-512 VBMI. Calif rates it CVSS 4.0 9.2, Oracle 8.1; Oracle fixed it in today's Critical Patch Update (655 fixes across products). Calif published a memory-corruption PoC but not the weaponised chains; no exploitation reported yet. It says the bug was found with OpenAI Codex in about an hour. Takeaway: patch Java runtimes now; stopgap is -XX:-UseBASE64Intrinsics or -XX:UseAVX=2.

CISA KEV: Puppet Enterprise deserialization RCE (CVE-2026-115731) exploited

CISA added the Perforce Puppet Enterprise flaw on 17 November: crafted rich-data in a report PUT lets any client with a CA-signed agent certificate run code on the Puppet Server as the service user, and if the CA auto-signs requests an unauthenticated attacker can get such a certificate. Federal deadline 1 December; ransomware use unknown. Takeaway: Puppet Server controls your whole fleet, so patch per Perforce's advisory and turn off CA autosigning.

RIKEN takes Fugaku offline after intruders stole user data and SSH keys

RIKEN says that between 10 and 13 November an attacker abused Fugaku's public status dashboard to reach several internal servers and plant malware targeting user data. Taken: names, emails and user IDs of 4,222 Fugaku users and 375 Rikyu users, plus SSH private keys, access keys and research files stored on users' machines; some keys were used to try other systems, with no further access found so far. Fugaku was shut down on 14 November and user login keys disabled; no attribution yet. Takeaway: anyone with Fugaku or Rikyu access should revoke stored keys and watch for RIKEN-themed phishing.

AI/Cloud

Researchers take over the Hugging Face account behind Kokoro TTS (13M downloads a month)

Researcher Alon Hertz's team registered the lapsed hexgrad.com domain listed in the project's files, reset the publisher's password and took control of the account; they then poisoned the model's weights in 87 seconds on a gaming GPU so it speaks different words, but did not upload them. Weight-only changes carry no code for scanners to catch. Kokoro appears in tooling and guides from Google, NVIDIA, Intel, AMD and AWS. Hugging Face has not responded. Takeaway: pin model revisions by hash and don't auto-pull new weights from unmaintained publishers.
