Drupal installer fix bypassed, exploited

Drupal's SA-CORE-2026-019 (CVE-2026-136716, "highly critical" access bypass, published Nov 25 at 18:04 CET) says sites in unusual or incomplete install states stayed open to takeover after the Nov 18 fix for the KEV-listed installer bug CVE-2026-132165, including production sites, and it is exploited in the wild. The vulnerable state is not visible in the UI, and already-compromised sites may no longer show it. Fixed in 11.4.14, 11.3.23 and 10.6.23, then run update.php; 11.0 to 11.2 and 10.5 and older get no fix. Takeaway: upgrade, run the update hook, block install.php and check logs for compromise since Nov 18.

Todoist breached via stolen dev credential

Todoist says that on Nov 22 and 23 an attacker used a stolen version-control credential to alter automated workflows in three repos, harvest more credentials and read source code (no code changes found), then took over an employee's work account and reached cloud infrastructure. Taken: email addresses, salted SHA1 password hashes and creation dates for about 6% of users; API and Slack integration tokens for about 0.003%; credential-like text searched out of customer content for about 0.001%; plus email data via connected Todoist for Outlook accounts. Leading theory is a compromised employee device (unconfirmed). Takeaway: if you got an email, change that password anywhere you reused it and reconnect integrations.
