Vulns

PHP2Shell moves from probing to confirmed remote code execution

Perplexity's detection lead Adel Karimi says his honeypots recorded a working exploit of CVE-2026-109618 and CVE-2026-109619 against Apache mod_php on PHP 8.4.26: an 800 KiB memory leak fed an address into the follow-up payload and a shell command ran about 1.6 ms later. Expel's Marcus Hutchins called it the highest quality confirmation he has seen. Until now, activity had been scanning and non-working exploits. Takeaway: anything still on an unpatched PHP (fixes shipped Oct 21) should be treated as exposed today.

Public root exploit for a Linux kernel flaw, no CVE or merged patch

ZDI-CAN-33367, a local privilege escalation in the kernel networking stack found by p1r0x, was posted to public lists with working exploit code. CloudLinux says its team used it to get root on AlmaLinux 8, 9 and 10, CloudLinux 9 and 10, Debian 12 and 13, and Ubuntu 24.04 and 26.04; CentOS 6 and 7 are not affected. It lets a local user alter the in-memory copy of read-only files such as setuid binaries or /etc/passwd. It needs local access, so shared hosts, CI runners and containers are the main worry.

Incidents

Token spray: stolen Microsoft 365 sessions replayed across 79 organizations

Huntress tracked a campaign from July 14 to September 22 that used an adversary-in-the-middle login page to steal sign-in tokens, then replayed them at scale: 200,000+ attempts from 193.26.115.0/24, 97 accounts compromised, 48 rogue Entra devices registered. In at least 19 organizations the attackers removed existing MFA methods and added their own within three hours, and set hidden inbox rules hiding payroll and deposit mail. Takeaway: review recent MFA method and device registrations, not just sign-ins.

Brotli bug reaches FFmpeg, ClickHouse and Apache Arrow through files

JFrog reported on Oct 25 that CVE-2026-111497 in Google's Brotli decoder also reaches FFmpeg (via a crafted JPEG XL image through libjxl), ClickHouse and Apache Arrow, and that some paths start with a file rather than a web request, so blocking Content-Encoding: br at the edge does not cover them. Per The Hacker News, ClickHouse and Arrow have no fix yet, while Microsoft has patched .NET. Restart services and rebuild images after updating.
