PHP2Shell plus the Fragnesia kernel bug rooted 25 firewall servers, including three in a US government-affiliated network

Dream says recovered attacker artifacts show a custom, non-public PHP2Shell exploit (CVE-2026-109618/109619) chained with Fragnesia (CVE-2026-46300, Linux kernel LPE) for unauthenticated root on an unnamed large vendor's firewalls running PHP 8.0.30. The attacker fingerprinted about 19,000 exposed management interfaces with FOFA, narrowed to 240 in the US, Japan, Taiwan and South Korea, and rooted 24 firewalls on Oct 23-24, then tunnelled to an internal management server and went after Active Directory (LDAP service password decrypted, users enumerated, password spraying). Whether credentials or backdoor accounts were gained is unknown. Claude Code and an "aiscan" platform using DeepSeek and Kimi were found on attacker infrastructure. Attribution is Dream's assessment, not confirmed; vendor not named. This moves PHP2Shell from limited real-world success to confirmed firewall compromise: check exposed firewall management interfaces.

Vulns

CVE-2026-97631: a 16-year-old EDK II PXE bug allows code execution before Secure Boot, with no firmware fix shipped

TianoCore's advisory (CVSS 9.5) describes a buffer overflow in the PXE driver's ICMP error handling: one oversized unicast ICMP error sent while a machine PXE-boots over IPv4 or IPv6 can hang the boot or, with a payload built for the exact firmware build, run ring-0 code before Secure Boot and measured boot. It affects EDK II-based UEFI firmware that network-boots (most servers); disk-only machines are not affected. The fix is merged upstream and in Microsoft's Project Mu, but no stable EDK II release or vendor BIOS update has it yet, and Red Hat and SUSE rate it adjacent-network. Found by Alex Matrosov (Anthropic) and Dan Holmes-Mitra (Google). No exploitation reported. Disable PXE where unused and watch for vendor firmware.

Moldova's government breach exposed data tied to about 750,000 ID numbers; PM probes foreign state involvement

Moldova's Electronic Governance Agency says attackers abused unauthenticated government services from Oct 19 to 23, making about 11 million requests and pivoting through interconnected systems. Exposed data may include names, birth details, family ties, health insurance, pensions, disability records, driver's licences, photos, vehicles and some financial data such as bank account numbers and tax debts; bank cards were not hit. 82 services were checked and over 30 systems disconnected; further attempts on Sunday and Tuesday failed. PM Vasile Tofan called it coordinated and is examining foreign state involvement; no attribution yet. Expect fraud and impersonation phishing aimed at Moldovans.
