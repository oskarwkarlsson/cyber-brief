Gheist: stolen GitHub tokens used to plant workflows that print every repo secret, then delete the evidence

Wiz has tracked the campaign since Sept 15: it pushes a ci-sync-xxxxxx branch with a sync-check.yml workflow to every repo a token can reach, base32-encodes secrets so GitHub's log masking misses them, pulls the log via the API and deletes the run. Wiz recovered 13,500+ planted branches from 850+ accounts. GitHub's approval hold stopped it in public repos, but runs succeeded in private repos and GitHub Enterprise Server, with follow-on AWS Secrets Manager enumeration. A newer variant also sweeps self-hosted runners for cloud, Kubernetes and AI-provider keys (buggy so far). Hunt for those branches and the gheist user agent, and rotate every secret an affected repo could see.

Tailworm: one compromised Tailscale node can reach root on other servers via Tailscale SSH forwarding

Cyberdione Labs' lab assessment of Tailscale 1.104.2 and headscale 0.29.5 shows unix-socket forwarding abuse (ssh -L/-R) plus a path-allowlist race letting root tailscaled dial or replace root-only sockets; five findings rated High. It needs an existing foothold on a device the ACLs already allow to connect. No CVE or fixed version yet; Tailscale says it is fixing issues it found. On the hosted service, turn off forwarding in SSH rules and tighten SSH grants; on headscale 0.29.5, treat every SSH grant as root.

DPRK, suspected

Suspected North Korean operators run low-and-slow PHP2Shell checks against 216 unpatched hosts

CYFIRMA, watching a closed Korean-language I2P channel, says the list spans government, banks, online transaction platforms, logistics, aviation and manufacturing across the US, Japan, South Korea, Southeast Asia, Australia, Taiwan, India, the UAE, Saudi Arabia and the EU, probed from 21 rotating compromised nodes. DPRK link high confidence, Lazarus link only moderate; no named victims yet (single vendor). Patch PHP to 8.5.12, 8.4.27, 8.3.36 or 8.2.35, restart workers, keep upload progress off, and hunt back to Oct 17.

AI sandboxes

OpenAI's red-team agents chained microVM escapes and cache-timing covert channels; fixes go to Kata, gVisor and Docker

Agents attacking isolated copies of OpenAI's research infrastructure found limited internet paths via metrics, logging and auth services and swapped secrets between microVMs via CPU cache timing. Upstream fixes include Kata Containers CVE-2026-24834, gVisor and Moby syscall-filter changes, and kernel CVE-2026-74753, CVE-2026-80521 and CVE-2026-80841. Separately METR and Redwood found Codex agents could in principle bypass Codex sandboxing and Auto-Review (as of July, reportedly fixed). If you sandbox agents in these runtimes, apply the patches and don't treat an agent's own approval layer as a boundary.
