European Commission confirms ARTEX-linked cyberattack

The Commission confirmed an "AI-generated cyber campaign" first detected October 22 that, per POLITICO, CERT-EU tied to ARTEX, the open-source AI hacking platform the FBI warned about last week. Personnel systems (payroll, leave, medical reimbursements, translation) were reportedly disrupted for more than 10 days. The Commission says it found no evidence of a broad staff data breach and no ransom demand, notified affected individuals and is checking other systems; the investigation is open. It is the Commission's third disclosed incident this year. Takeaway: ARTEX intrusions now include an EU institution; treat internet-facing devices and HR/payroll platforms as priority targets.

Cisco Expressway root RCE exploited after PoC

F6 says attackers exploited CVE-2026-76466 (CVSS 9.8, unauthenticated root command execution in clustered Expressway Core/Edge) at a Russian organisation soon after a PoC appeared on GitHub. They breached two internet-facing X15.5.3 nodes, pivoted to two internal cluster nodes, and staged Python tooling for SMB, SQL Server, WinRM and GitLab credential hunting, with code comments suggesting an AI assistant. Cisco's advisory still says it knows of no malicious use; no attribution. Takeaway: upgrade to X15.5.20 (X14 and earlier must move to a fixed release); if you can't, block TCP 4371-4372 except from trusted cluster nodes and check the Erlang system log.

VMware vCenter 9.8 auth bypass (VMSA-2026-0009)

Broadcom fixed CVE-2026-123890, an authentication bypass in the VMware Directory Service that lets anyone with network access to vCenter gain unauthorized access; no workaround, reported by Mandiant, and Broadcom calls it an ITIL "emergency change". Fixed: vCenter 9.1.1.0200, 9.0.2.0200, 8.0 U3m, VCF 5.2.5; 7.0 only via extended support, and 6.5/6.7 should be presumed affected. No exploitation or public exploit reported, but the same component's July bugs were attacked within days. Four lower-severity SDDC Manager and VMware Tools fixes ship alongside. Takeaway: patch vCenter now and keep it off untrusted networks; note the 8.0 U3m/9.0.2.0200 upgrade-path conflict with VCF 9.1.1.

Drupal core: critical installer takeover

Drupal fixed CVE-2026-132165, which lets anonymous users abuse install.php to reinstall Drupal under specific conditions, leading to site takeover or RCE; found by Anthropic's OSS Scanner. The security team warned exploits "might be developed within hours or days". Fixed in 10.6.22, 11.3.22 and 11.4.13; a moderately critical admin-only gadget chain (CVE-2026-132166) is also fixed. No exploitation reported yet. Takeaway: upgrade, or block /core/install.php in the web server config until you can.
