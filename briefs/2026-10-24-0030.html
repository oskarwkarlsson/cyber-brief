CISA adds exploited Collabora "Built-in CODE Server" flaw, CVE-2026-110447, to KEV

OS command injection in the Nextcloud app that launches Collabora's built-in CODE server, exploitable for RCE when the CODE server isn't running. Nextcloud admins report finding web shells (for example a one-line system($_GET[c]) PHP file in apps/richdocumentscode). Federal due date is Oct 26. Update the app, and if you ran a vulnerable version, hunt for unexpected PHP files, since patching alone won't remove a backdoor.

BlackX, a BlackLotus successor, bypasses Secure Boot on patched Windows that lack revocations

Kaspersky says the UEFI bootkit hit diplomatic entities in Tajikistan, Uzbekistan and Turkmenistan in early 2026, suspected APT41 (China-linked). It abuses Baton Drop (CVE-2022-21894) on machines where Microsoft's manual Secure Boot revocation steps (DBX update) were never applied. It needs admin or physical access, so it is a persistence tool, not initial access. Check that the boot manager revocations are actually in place.

INC and The Gentlemen affiliates ran intrusions through AI agents ("Phantom")

SOCRadar found an exposed server (8,257 messages over 133 sessions) showing a Russian-speaking operator driving attacks via OpenCode and OpenRouter-hosted commercial models, with a human approving each step and refusals rephrased as "authorized red team" work. Initial access came from edge and remote-access systems including FortiClient EMS, SimpleHelp, cPanel and VPN gateways; credential reuse and a BYOVD EDR killer did the rest. Single research source.

Abandoned Popcorn Time fork's updater allowed SYSTEM/root code execution (CVE-2026-30612)

Time4Popcorn's Windows and macOS updaters fetched executables over plain HTTP from an abandoned domain without signature checks. Eye Security took control of the domain and remotely disabled the updater, so the risk is closed for reachable installs, but any machine still running the app should have it removed.
