GL.iNet GoodCloud flaw exploited to backdoor routers and KVMs

GL.iNet says an unauthorized party exploited a vulnerability in its cloud remote management service to install malware on some of its routers and KVM devices (advisory issued Nov 20, updated Nov 21). The cloud hole is closed, so no new infections through that path, but already infected devices stay infected. GL.iNet has not said how the flaw worked or how many customers were hit. BleepingComputer's analysis of the installer (ni.sh) found code aimed at GL.iNet models, persistence through startup scripts and scheduled tasks, SSH key planting, a fake netstat that hides its C2 traffic, and Chinese-language developer comments. Users report root reverse shells, and RemoteToHome Consulting found suspicious activity on 152 of 183 routers it manages (some may be older, unrelated backdoors). KVM owners should treat the computers attached to an infected KVM as possibly compromised. Check for a process showing crond -i /tmp/.log, consider switching off GoodCloud, install the security firmware (stable releases scheduled for Nov 22; KVM 1.10.3 or later for most models), and factory reset without restoring old configs if infected.
