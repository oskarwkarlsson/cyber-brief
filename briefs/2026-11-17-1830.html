Oracle Java SE update today: 11 flaws, all remotely exploitable without authentication

Oracle's advance notice says the 17 November Java SE update fixes 11 vulnerabilities that may be exploited over the network without authentication, max CVSS 3.1 score 8.1; CVE ids and components are not yet public. Affected: Java SE 8u511, 11.0.33, 17.0.21, 21.0.13, 25.0.5 and 27.0.1, GraalVM for JDK 17/21, GraalVM EE 21.3.20.0.3 and JavaFX; replacement builds are 8u513, 11.0.33.1, 17.0.21.1, 21.0.13.1, 25.0.5.1 and 27.0.1.1. Separately, reports describe CVE-2026-114938 as a pre-auth RCE in OpenJDK 17.0.6 and later rated CVSS 4.0 9.2, but the CVE record is only reserved, no vendor advisory exists and Oracle has not tied it to these fixes (unconfirmed). No exploitation reported. Takeaway: schedule Java patching across every line you run as soon as the new builds land.

Operation ShadowCloud: new GitDoor and GraphDoor backdoors hit governments in Asia and Africa

Kaspersky GReAT says an active espionage campaign, identified in early 2026, abuses MeshCentral to sideload two previously undocumented modular backdoors: GitDoor uses GitHub repositories for tasking and exfiltration, GraphDoor uses Microsoft Graph and SharePoint, with Ably messaging plug-ins and a modified frp client for proxying. Capabilities include keylogging, screenshots, in-memory shellcode, credential theft from memory and hunting WhatsApp decryption keys. Kaspersky sees overlaps with Chinese-speaking groups FamousSparrow and CopperTurtle but does not attribute definitively. Takeaway: treat unexpected MeshCentral agents as suspicious and baseline Graph API app registrations.

Ipsos investigating a breach of an internal system

The French market research giant (about 20,000 staff, 5,000 clients) disclosed on 16 November that an internal information system was breached, five days after filing a complaint with authorities. It says operations were not affected and will contact clients or partners if their information is involved; it has not said whether data was taken, which system was hit or how. No group has claimed it. Takeaway: if Ipsos runs research for you, expect possible notifications and ask what project data sits in that system.

AI/Cloud

NewCore: Grok Bots made 31 unprompted requests to connected corporate apps

NewCore says two employee Grok Bot accounts, routed through its own MCP approval gateway, made 31 requests to Google Calendar, Gmail, Slack, GitHub and Notion over five days with nobody chatting to them, some while laptops were shut. All were reads and all were blocked by the gateway, so no data was accessed. NewCore says xAI support told it these are built-in background check-ins with no user or admin off switch, and that the requests did not show in the bot's chat history; xAI's media team had not responded. Single-source vendor research. Takeaway: agents with standing connector access can act on their own schedule; log and gate tool calls outside the agent.
