SSHole is now on CISA KEV: OpenSSH on Linux auth bypass, patch by 12 November

CISA added CVE-2026-123158, the OpenSSH password-authentication bypass on Linux known as SSHole, to its Known Exploited Vulnerabilities catalog today, with a due date of 12 November and forensic triage required. We first flagged exploitation attempts on 8 November; KEV listing is CISA's confirmation that it is exploited in the wild. CISA points to the OpenSSH release notes, Alpine's 5 November advisory and the upstream fix commit. Takeaway: update OpenSSH everywhere it faces the internet, and check auth logs on anything that was exposed before patching.

Two more KEV adds: GPUStack admin takeover and FreeSWITCH remote command execution

Also added today, both CVSS 9.8 and due 12 November. GPUStack, a popular open-source GPU cluster manager for serving AI models, before 2.2.0 treats any request that looks like it comes from localhost as the built-in admin; behind a same-host reverse proxy, or with a forged X-GPUStack-Real-IP header, that is every request (CVE-2026-102895). Attackers get admin API keys, worker and cloud-provider secrets and code execution. FreeSWITCH up to 1.11.2 lets anyone who can send a SIP MESSAGE pick a server API command to run, giving OS command execution, credential disclosure and call control (CVE-2026-116779, fixed in 1.11.3); the project's own advisory says exploitation has been observed. Takeaway: upgrade GPUStack to 2.2.0+ and FreeSWITCH to 1.11.3+, and rotate any secrets those hosts held.

Supply chain via trust policies: attacker used Qubole's AWS account to assume roles in customer clouds

Wiz, working with Sentra and Mandiant, says that between 14 and 26 October an actor used IAM credentials from an AWS account associated with Qubole (the data platform vendor) to assume the cross-account integration roles customers had created for it. Every attempt carried a valid External ID and succeeded; most of those roles were otherwise unused but still trusted. Inside, the actor enumerated broadly, pulled Lambda environment variables, Secrets Manager and SSM parameters, downloaded whole S3 buckets, and tested found AWS, Entra ID and Okta credentials with TruffleHog. Wiz has not said how the vendor credentials were obtained. Takeaway: audit roles that trust Qubole's account (805246085872), remove stale vendor trust policies, and turn on S3 data events so object reads are logged.

AI/Cloud

German web host Mittwald breached through its MCP server, attacker allegedly AI-assisted

Mittwald CM Service, a hosting provider for web agencies, disclosed on Saturday that an attacker compromised 56 customer projects and went undetected for eight days after exploiting a flaw in the Model Context Protocol (MCP) server it offers so customers can connect AI assistants to its mStudio platform. Its managing director says logs showed only seconds between steps and suspects AI tooling, but the company has given no other evidence of AI use, and it is unclear whether the flaw was in Mittwald's code or open-source MCP libraries. No further attacker activity was detected as of Friday; a detailed write-up is promised this week. Takeaway: an MCP endpoint is an internet-facing admin API and needs the same auth and monitoring.
