Mitel MiCollab zero-days hit KEV

CISA added five unauthenticated Mitel MiCollab AWV flaws to KEV on Nov 25 (CVE-2026-133323 command injection, -133275 file upload, -133303 XML injection, -133324 auth bypass, -133311 weak auth) from advisory MISA-2026-0012; four are due Nov 28, one Dec 9. Accenture APEX Labs assesses with high confidence they were exploited before Mitel's Nov 16 patch: one attacker reached root in 30 minutes and used MiCollab's stored LDAP credentials to log on to a domain controller in 32, likely with AI-assisted tooling. No actor named. Takeaway: patch, then hunt with Accenture's indicators.

1Password breached via employee GitHub

From Nov 19 an attacker used a hijacked employee GitHub account to read private repos, copy source code, reach CI/CD and push code to backend services that pulled account records for a small number of users: names, emails, account IDs, sign-in times, public keys, SRP parameters and invitation, provisioning and recovery link tokens. Vaults, recovery keys and the keys protecting them were not touched and no takeovers were found; emailed codes are now 10 characters instead of 6 digits. Takeaway: expect 1Password-themed phishing; never hand over a Secret Key or recovery code.

Hex.pm registry servers hacked via CVSS 10 flaw

On Nov 23 an attacker exploited CVE-2026-129514 (CVSS 10.0) in the pre-auth request parser of hex.pm, the Elixir and Erlang package registry, a bug present since 2016, and ran OS commands on six production web servers. Hex found no package or database changes, but database reads are not logged, so emails, password and API key hashes, 2FA secrets and sessions may have been read. All infrastructure credentials and session keys were rotated; the registry signing key is not yet. Takeaway: hex.pm users should change passwords and reset 2FA, and fetch only from repo.hex.pm until new clients ship.

State hackers adopt the Artex AI tool

Microsoft says Salt Typhoon, Crystal Typhoon, Onyx Sleet, Pearl Sleet, Storm-0940 and Storm-3358 now use Artex for recon, credential attacks and web app exploitation, going from recon to privileged access in minutes; the durable signal is machine-speed bursts of varied requests from one source. The NYT and Nextgov report (anonymous sources) that the CIA and at least two other US spy agencies had unclassified data exposed in Artex-assisted intrusions. Italy's CSIRT and Switzerland's NCSC also warned of autonomous agent attacks, with Switzerland reporting its first successful ones.
