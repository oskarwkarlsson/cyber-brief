Azure APIM Classic flaw exploited to target stored secrets

Norway's NSM says an unidentified actor exploited a vulnerability in Azure API Management to go after access tokens, secrets and named values, hitting Equinor and Skagerak Energi and organisations in several sectors in Norway and abroad. A Microsoft customer notice shared on Reddit (not public) says the issue was found Nov 18 and the access path closed Nov 19; Classic tiers not following Microsoft's guidance were exposed, v2 tiers were not. Microsoft has not commented publicly or given a customer count. If you run APIM Classic: rotate named values, identity provider client secrets, subscription keys and management tokens, and check what they can reach.

CISA KEV: N-able Mail Assure and MONAI Label, due Nov 26

CISA added two exploited flaws on Nov 23 with a three-day deadline and forensic triage required. N-able's Mail Assure / SpamExperts SSRF CVE-2026-134624 (9.3) was found during N-able's own breach investigation and fixed in build 20261121.1943; the KEV listing is the first confirmation it was exploited. MONAI Label CVE-2026-133968, the unauthenticated file-write bug Amazon says Chinese operators' Cairn AI agents found and used for root at East Asian universities, now has a fix: the advisory lists 0.8.6 (released Nov 22) as patched.

Idunno.AntiCsrf CVE-2026-131914: exploited, never to be patched

Mandiant says attackers are using a deserialization flaw in Idunno.AntiCsrf, an ASP.NET WebForms module last released in 2008, to run code as w3wp.exe with one unauthenticated POST (CVSS 4.0 score 9.3). The project is dead, so the only fix is removal: search Web.config and bin/ for Idunno.AntiCsrf or AntiCsrfModule, replace it with AntiForgery or ViewStateUserKey, review IIS logs, and rotate machineKey if hit. Not in KEV yet.

Wiz: agentic intrusions accelerating

Wiz Research says twenty more incidents linked to agentic offensive frameworks have been disclosed by vendors in the three weeks since its "Black October" post, and its incident response requests are up threefold. It tracks about a dozen campaigns; one, "ARTEX-Harvester", hit more than a dozen organisations from late October to mid-November, rotating through 220+ residential proxy IPs at a single target, then pivoting from stolen VCS credentials through CI workload identity into cloud and mining AI coding-assistant histories for SSO credentials. Wiz stresses ARTEX has hundreds of forks used by unrelated operators, so "ARTEX" activity is not one actor. It recommends behavioural detections (mass secret retrieval, odd IAM enumeration, off-platform credential use) and publishes 200+ IOCs.
