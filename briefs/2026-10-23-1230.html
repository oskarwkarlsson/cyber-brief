Pillow 13.0.0 fixes critical code-execution bugs in Python's main image library

CVE-2026-112900 (GitHub CNA score 9.2): an attacker-controlled EPS filename is passed to Ghostscript unchecked and can run OS commands on hosts with gs installed; affects Pillow 2.6.0 to 12.3.0. Separate critical fixes cover stale image storage reuse after mode changes and JPEG/FlashPix overflows, one shown to run a command from a single Image.open(). No exploitation reported. Upgrade to 13.0.0, especially upload and ML pipelines.

Quest Diagnostics reports unauthorized access to patient records

Quest told regulators it found unauthorized access on Oct 21 to Quanum Lab Services Manager, the platform clients use to place test orders and look up results; certain patient records were accessed. Scope and attacker not disclosed; some systems were temporarily taken offline and law enforcement is involved. Expect healthcare-themed phishing.

Node2Shell: Imperva gets code execution on official Node.js via Brotli bug (CVE-2026-111497)

Earlier PoCs only crashed standard builds. Imperva ran code on the official Node.js 24.22.0 Linux arm64 image through Express 5 body parsers and through fetch() responses, after several attempts. Affects the 22.x, 24.x and 26.x lines; 24.22.1 blocks it. No in-the-wild exploitation reported. Patch services that decode untrusted Brotli.
