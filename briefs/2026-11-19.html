CISA KEV: LiteLLM, REDCap, Apache Axis and Synology DSM all exploited

CISA added four actively exploited flaws on 18 November: BerriAI LiteLLM CVE-2026-40217 (code execution via the /guardrails/test_custom_code endpoint, due 2 December), Vanderbilt REDCap CVE-2026-90817 (unauthenticated code injection), Apache Axis CVE-2026-90436 (unauthenticated RCE via a crafted SOAP fault) and Synology DSM CVE-2024-10441 (RCE in the system plugin daemon). The last three are due 21 November. CISA lists ransomware use as unknown for all four. Takeaway: LiteLLM proxies and REDCap research servers are often internet-facing; patch or take them off the internet now.

F5 patch day: NGINX HTTP/2 RCE pair plus six critical BIG-IP data-plane bugs

F5 published 22 advisories on 18 November. NGINX 1.30.7 and 1.31.9 fix a use-after-free (CVE-2026-123633) and flow-control memory corruption (CVE-2026-123007, back to 1.9.5) in HTTP/2; Wiz says both give unauthenticated RCE with HTTP/2 enabled, even on a static-file server. Separately, six BIG-IP stack overflows (CVSS 9.8, iRules using PEM::subscriber, MR::message route, PSC::ip_address, GENERICMESSAGE::route or DNS::scrape, and one APM policy combo) can crash TMM unauthenticated and may allow RCE; fixes are engineering hotfixes only, no workaround. No exploitation reported for either yet. Takeaway: upgrade NGINX (and watch Plus, ingress and distro builds) or disable HTTP/2 on exposed listeners; audit iRules for those commands.

Vulns

Apache Roller pre-auth RCE (CVE-2026-129448, CVSS 9.8) exploited

Apache says Roller's XML-RPC endpoint deserializes extension types before authentication, giving unauthenticated code execution on 4.0.0 through 6.1.4, and that it is actively exploited. It is the same bug as CVE-2026-82384, which had listed only 6.1.5, so older installs may have assumed they were safe. No attacker or victim details. Takeaway: upgrade to 6.1.6, or set enabledForExtensions to false or remove the /roller-services/xmlrpc mapping; turning XML-RPC off in the admin UI is not enough.

Ukraine and FBI arrest four in $40.5m ransomware network using AI-voiced vishing

Ukrainian police, with the FBI, ran 66 searches and detained four suspected key members of a group of at least 27 tied to more than $40.5m in ransoms from at least 28 companies, part of a 60+ member network that includes ex-Conti members. Court records name Chaos ransomware. Initial access came from fake IT support calls using AI-generated voice messages, VPN phishing pages and remote tools. Takeaway: treat unsolicited IT support calls asking for MFA codes or remote access as an attack.
