Vulns

Cisco ASA and FTD: exploited zero-day (CVE-2026-76418) lets anyone crash SSL VPN firewalls

Cisco says it learned in October that this flaw was being exploited. An unauthenticated attacker sends a crafted request to the Remote Access SSL VPN and the firewall reloads; no successful login is needed. Only tunnel groups using secondary authentication are exposed. CVSS 8.6, no workaround, but turning off the tunnel group list or secondary auth reduces exposure. Fixed in ASA 9.16.4.104 through 9.24.1.27 and FTD 7.0.11 through 10.1.1. SecurityWeek calls it the second exploited Cisco firewall VPN zero-day since August.

Palo Alto confirms PHP2Shell attacks on internet-facing PAN-OS management interfaces

Palo Alto updated its advisory today: exploit maturity is now ATTACKED for CVE-2026-109618/109619 on PA-Series, VM-Series and Panorama. It names the vendor behind the attacks earlier described by Dream as an unnamed firewall vendor (that link is THN's inference; Palo Alto does not cite Dream). Fixed hotfixes are listed for PAN-OS 10.2 to 12.2, but one 11.1.7 fix is still due Oct 30. Restrict the management interface to a jump host now. JPCERT also updated its alert.

Vectors

Alpine Linux GitLab: attacker came close to exploiting CVSS 10 CVE-2026-97229; upgrading GitLab alone did not fix it

A new account sent crafted CI configs on Oct 20 and 21, crashing workers 8 times and getting partway through the exploit 4 times. Alpine finds no evidence of code execution but cannot rule it out, so it rebuilt the server and reset all passwords. Releases, packages and signing keys checked clean. Key lesson: the fix lives in GitLab's patched Ruby, so anyone running GitLab on their own Ruby also needs Ruby 3.3.13, 3.4.12 or 4.0.9.

NIK C2: new in-the-wild C2 framework pipes stolen data to OpenAI and can bill the victim's API key

Talos describes a Go Windows implant with 50+ commands: credential, wallet and Wi-Fi theft, live keylogging, HVNC, proxying, AMSI bypass and a screen-locking ransomware module. Its ai_generate command calls OpenAI's Chat Completions API from the victim's machine and falls back to the victim's OPENAI_API_KEY. Talos saw a live panel at 87.120.196[.]120 (moderate confidence it is operational, not a PoC).
