Node-RED CVE-2026-58115 is now exploited in the wild

VulnCheck saw the first successful exploitation on October 30 and 15 more attacks from the same Microsoft-network IP by November 1. The bug (CVSS 10) is missing authentication on the Node-RED HTTP interface, so one request can deploy a flow that runs system commands. Payloads were a multi-architecture Linux bot and persistent webshells. Siemens found it in SIMATIC IoT2050 Advanced (fixed in 4.3.4.1 and later), but Node-RED ships inside many ICS/OT products. Takeaway: find any Node-RED instance without adminAuth that is reachable from outside and check deployed flows for unexpected exec nodes or HTTP endpoints.

Barracuda: two flaws chain to root on ESG and five other appliances

CVE-2026-116606 (critical) is an authentication weakness in Email Security Gateway that lets an attacker change the global configuration; CVE-2026-111560 is admin-level OS command injection running as root in ESG, Load Balancer ADC, Message Archiver, WAF, WAF Control Center and Web Security Gateway. Both need access to the admin interface. No exploitation reported yet, but Barracuda ESG was a China-nexus zero-day target in 2023. Takeaway: apply the patches and keep admin interfaces off the internet.

Binance post-mortem: a months-long North Korean campaign, not one breach

Binance says it began in June when an engineer downloaded malicious software posing as an installer for a popular AI coding tool. The device was caught and replaced, but the attackers had already learned about the engineer and the developer team. They then combined fake recruitment interviews, malicious downloads, compromised internal AI tooling, endpoint compromise and an advanced transaction-authorisation method. Binance says it stopped 57 other North Korean attempts in 2026. North Korea denies responsibility. Takeaway: developer tool installers and AI tooling are now a primary entry point for TraderTraitor-style attacks.

Vectors

3AM ransomware affiliate likely ran an AI agent loop against UK schools

Bitdefender says an affiliate encrypted about 37 of nearly 50 machines it reached at a UK school estate in September. Commands were retried with small changes every 40 to 100 seconds, which looked like an automated agentic loop, though Bitdefender could not confirm which model was used or whether a human was copying output. The attacker pulled credentials from three Veeam backup servers, created backdoor domain admins named "library" and "svc_bkpmon", and set up two-way trusts between three separate AD domains before trying to strip Sophos and Bitdefender protection.
