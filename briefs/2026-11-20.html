Vulns

vCenter CVE-2026-123890 was a zero-day

Broadcom's emergency fix (VMSA-2026-0009) closed a 9.8 auth bypass in the VMware Directory Service; Google/Mandiant then said suspected PRC-nexus ARMORY CASTLE (formerly UNC5221) exploited it from early September, entering via the BeyondTrust Remote Support zero-day CVE-2026-102764 and using a Go tool, BONESAW, to steal the STS SAML signing key, create an SSO admin and forge tokens before moving to ESXi. It worked on vCenters already patched for July's bug; 7.0 has no public fix. Not yet in CISA KEV. Takeaway: patch to 9.1.1.0200, 9.0.2.0200 or 8.0 U3m, restrict port 2012, hunt for new SSO admin or machine accounts.

European Commission confirms ARTEX-linked attack

The Commission confirmed an "AI-generated cyber campaign" first detected October 22 that, per POLITICO, CERT-EU tied to ARTEX, the open-source AI hacking platform the FBI warned about last week. Personnel systems (payroll, leave, medical reimbursements, translation) were reportedly disrupted for more than 10 days. No broad staff data breach found and no ransom demand; the Commission did not name the tool itself. Separately, Cloudflare saw one IP running both ARTEX and Java4Shell activity. Takeaway: treat HR and payroll platforms and internet-facing devices as priority targets.

Cisco Expressway root RCE exploited after PoC

F6 says attackers exploited CVE-2026-76466 (CVSS 9.8, unauthenticated root command execution in clustered Expressway) at a Russian organisation soon after a GitHub PoC, pivoting from two internet-facing X15.5.3 nodes to internal cluster nodes and staging Python credential-hunting tools whose comments suggest an AI assistant. Single-source; Cisco's advisory still reports no malicious use, and there is no attribution. Takeaway: upgrade to X15.5.20, or block TCP 4371-4372 except from trusted cluster nodes.

Vulns

Java4Shell attempts begin, NGINX2Root PoCs public

GreyNoise, watchTowr and Previdian logged Java4Shell (CVE-2026-114938) recon and exploit attempts, with no confirmed compromise yet; Cisco lists 12+ affected products without a fix and Atlassian advises disabling AVX-512 on Data Center until patches ship. CrowdStrike notes exposure needs an affected JDK, AVX-512 VBMI x86 CPUs and attacker-supplied Base64. Meanwhile Rapid7 and Censys published PoCs for NGINX2Root (five critical nginx bugs; Censys counts about 9 million exposed services); no in-the-wild exploitation reported. Takeaway: patch JDKs on internet-facing x86 Java services and move nginx to 1.30.7/1.31.9 or disable HTTP/2.
