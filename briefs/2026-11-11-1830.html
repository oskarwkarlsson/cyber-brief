Incidents

Maersk confirms unauthorised access and data extraction from a legacy acquired system

A.P. Moller-Maersk says attackers accessed and extracted data from "one of our local legacy systems from a previous acquisition". It says findings so far "strongly suggest no sensitive data has been disclosed", the incident is isolated, and API/EDI integrations and bookings are unaffected. WhiteArmor claims about 100 GB from the LF Logistics platform (acquired 2022), including 29,297 driver profiles with 16,093 plaintext passwords, 33 SUPER_ADMIN accounts and 14.44M inventory rows, and demands $5M in bitcoin (claim, unverified; Maersk has not named the group). Takeaway: if you work with Maersk/LF Logistics warehousing in Asia, expect Maersk-themed phishing and rotate any shared credentials.

AI/Cloud

AntiFox, an open-source AI pentest agent, used to web-shell IIS servers and read AWS production secrets

Arctic Wolf Labs links Alibaba Cloud hosts running AntiFox (an agentic pentest framework derived from ARTEX, created on GitHub in October) to real intrusions: an ASPX web shell spawned by w3wp.exe on compromised IIS apps, harvesting of web.config connection strings, then valid IAM users and an assumed EC2 role firing hundreds of AWS API calls in about 30 minutes. Most were denied, but one run got a successful GetSecretValue on a production secret and another did S3 copy and delete. Initial exploit is unknown. Takeaway: alert on GetSecretValue and S3 deletes from new ASNs, and don't treat a burst of AccessDenied as a failed attack.

Vulns

Ivanti EPM unauthenticated SQLi RCE (9.8) and Zoom Workplace for Windows privilege escalation (9.6)

Ivanti's November update fixes 13 CVEs, led by Endpoint Manager CVE-2026-121653 (CVSS 9.8, unauthenticated SQL injection to RCE, fixed in 2024 SU8) and Cloud Services Application CVE-2026-121683 (9.4, unauthenticated add/delete of trusted EPM Core certificates, fixed in 5.0.8.1). Zoom's ZSB-26023 fixes CVE-2026-108186 (9.6, network privilege escalation, user interaction required) in Workplace for Windows 7.1.0 to 7.1.7. Neither vendor reports exploitation. Takeaway: EPM servers are a past favourite target, patch them first; push Zoom 7.1.8.

Incidents

Poland takes ePUAP e-government platform offline after a cyberattack

Digital Affairs Minister Krzysztof Gawkowski says an attack on ePUAP, the national platform for submitting documents to agencies, was "detected and stopped". The ministry says the system was disabled as a precaution, not because it was compromised, and Central IT Center infrastructure is secure. Mailboxes are unavailable and the Trusted Profile e-ID may be affected; no restore timeline, method or actor disclosed. Takeaway: another hit in Poland's run of government and health-sector incidents; watch for attribution.
