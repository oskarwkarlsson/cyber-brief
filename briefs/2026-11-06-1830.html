SSHole (CVE-2026-123158): exploitation within hours; root confirmed on Alpine honeypot

This morning's daily flagged OpenSSH 10.6p2 for a musl password-auth bypass with no exploitation reported yet. Previdian now says the first attempt came less than nine hours after the CVE published, and it confirmed successful root on an Alpine Linux OpenSSH honeypot. Telemetry shows eight attempts from 89.116.89.18 (Japan geolocation), using oversized passwords and running id, uname and hostname over non-interactive SSH. The bug (CVSS 8.1) hits musl systems with PAM off; password-disabled accounts that store "*" as the hash can be logged into with a 257-1,024 byte password. Glibc and PAM setups are out of scope. Takeaway: patch to 10.6p2 or your distro build now, and on Alpine check sshd logs for "Accepted password for" on accounts that should never take a password.

QNAP: Plex2Shell is compromising customer NAS devices

QNAP says it has received reports that Plex Media Server on customer NAS boxes appears compromised through the Plex2Shell chain (CVE-2026-96652, -96654, -96655, -96656), and support is assisting affected users. Plex has confirmed active, widespread exploitation of internet-facing servers since a public PoC on October 16; CISA put all four on KEV on October 20. Compromised servers have run cryptocurrency miners and proxy software. The flaws live only in Plex, not in QTS or QuTS hero. Fixed Plex 1.43.3.10861 is in the QNAP App Center. If Plex was reachable from the internet on 1.43.2 or earlier, QNAP says updating alone will not clear payloads: treat the NAS as compromised, clean-reinstall the OS, and reset Plex and NAS credentials. Takeaway: update Plex now, pull port 32400 / Remote Access unless you need it behind a VPN, and reinstall if it was exposed.

D-Link: multiple unpatched zero-days in DGS-3130 managed switches

D-Link published mitigations for multiple unpatched flaws in DGS-3130 series Gigabit stackable switches, found by Spectrum Community Solutions engineer Giresh Kumar Enugu in the D-Link Discovery Protocol (DDP) authentication, access control and information handling. Successful exploitation on the local network can leak device data and SNMP communities, change credentials or configuration, disrupt service or reset the device. No CVE IDs yet; impact on other D-Link platforms is still under review. Until firmware ships, D-Link says disable DDP, strip default SNMP communities, and keep SSH, web UI and SNMP on isolated management networks only. Takeaway: kill DDP on DGS-3130 stacks today and treat management interfaces as air-gapped until a patch lands.

AI/Cloud

Browser extension + Claude Dispatch can run code on the desktop

Forever Security showed that an extension able to script claude.ai can abuse Claude Dispatch to send tasks to Claude Desktop as the signed-in user, auto-click Allow prompts in the page the extension controls, and get Claude to install packages or otherwise act with desktop permissions. The demo opened Calculator via an npm install script; the same path could steal files or plant a backdoor. No real attacks reported. Anthropic told the researchers Dispatch would retire by end of October; the help page still says existing Pro/Max/Ultra users can keep using it. The researchers say Claude Code Remote Control and Cowork sessions share the design risk. Takeaway: turn off cross-device Dispatch if you do not need it, and treat extensions on claude.ai like other endpoint software.
