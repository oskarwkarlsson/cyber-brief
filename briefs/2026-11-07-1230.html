Claude Code saves secrets in plaintext settings files that end up on GitHub

When a Claude Code user picks "Yes, and don't ask again" on an exact command, the command is saved word for word, secrets included, in .claude/settings.local.json. Claude Code adds that file only to the user's global git excludes, not the project's .gitignore, so it gets committed elsewhere. Per The Hacker News, citing Apiiro research, 1,122 of 104,185 public copies of the file hold at least one secret (1,379 distinct secrets), including 379 database passwords, 43 SSH logins, 42 GitHub, GitLab and npm tokens and 23 AWS keys, across 63 organizations; in 539 repos a commit co-authored by Claude changed the file. One notified company confirmed its key was live; no abuse is reported yet. Takeaway: search your repos and forks for .claude/settings.local.json, rotate anything it ever held (deleting it does not clear git history), and add it to each project's .gitignore.

AI persona "thirst trap" accounts on X push malware via fake tutorials

vx-underground says an active campaign uses verified X accounts with AI-generated female personas to build a following, then posts tutorials whose PowerShell snippets hide a tiny IEX call to a decimal-encoded IP address that pulls a payload, with the rest of the script looking legitimate. It notes an AI assistant judged the sample as legitimate because the malicious part is so small. Single source, no vendor write-up yet. Takeaway: treat copy-paste commands from social media tutorials as untrusted, and alert on PowerShell IEX with numeric IP hosts.
