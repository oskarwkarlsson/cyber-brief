Chainalysis breach grows: names, usernames, password hashes and live tokens of all users exposed

In an update posted Wednesday night, the blockchain analytics firm said "certain customer information including names, usernames, password hashes and live tokens for all Chainalysis users" was exposed. Its first disclosure on October 30 said it had seen no sign that credentials or session tokens were accessed. Chainalysis, whose customers include law enforcement and national security agencies, still says it has no evidence investigations data was accessed or attribution data manipulated. It has not named the attacker, explained "offensive agentic techniques", or said how passwords were hashed. All users must reset passwords and rotate API keys. Takeaway: treat any Chainalysis session or API key as compromised, and expect phishing posing as reset emails; go to the login page directly.

CERT-In: "Crafty Falcon" uses AI offensive tools to steal from Indian banks, fintechs and crypto firms

India's CERT-In issued a Critical advisory (CIAD-2026-0058, November 4) on an active, AI-assisted actor it calls Crafty Falcon, updating its October 9 alert on abuse of payment and disbursement APIs. Per CERT-In as reported by The Hacker News, the actor uses public AI offensive tools such as ARTEX, PentAGI, Cairn and CyberStrikeAI, rotates infrastructure within hours to days, steals payment gateway and partner-bank API credentials and calls fund-transfer APIs from the victims' own allow-listed systems, bypassing KYC and limit checks. Crypto exchanges have lost keys and funds. Takeaway: payment API credentials and non-production environments are the soft spot; lock them down and watch for direct API transfers.

GhostMap: unpatched Android flaw lets a permissionless app trap a phone in a boot loop

Bitdefender found the flaw while analysing an Android banking trojan that kept crashing its emulators. Two Android libraries read ZIP compression methods differently, so a malformed APK can be mapped past its real contents and the reading process crashes. A proof-of-concept app with no code and no permissions, which never has to be opened, causes a persistent denial of service. Bitdefender says Google has known since August but closed the report as "not reproducible" without a patch. Takeaway: no fix yet; the real-world use so far appears to be anti-analysis in malware, but sideloaded apps could weaponise it.
