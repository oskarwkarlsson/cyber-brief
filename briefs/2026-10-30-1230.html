Supply chain: a malicious Anthropic.claude-code 2.1.313 build in Cursor's extension marketplace installed an SSH backdoor

Cursor says a modified version of the Claude Code VS Code extension, not built by Anthropic, was available in its marketplace from about 2:27am to 1:35pm PT on Oct 29, reaching at most 5,000 users. On load it collects host and user details, adds an attacker SSH key (comment svc-telemetry) to authorized_keys, tries to enable SSH and open a reverse tunnel, installs persistence (LaunchAgent on macOS, scheduled task or Startup script on Windows) and beacons to port 8099. Enabling SSH needs admin rights, so the tunnel failed on most macOS and Windows hosts, but the key, persistence and beacon still land. Cursor pulled the build, rebuilt its marketplace, rotated keys and had the attacker server taken offline. How the attacker published under the real extension's identity is not yet explained. If affected: check for the svc-telemetry key, run Cursor's remediation script (uninstalling is not enough), rotate credentials from a clean machine, update to 2.1.314. Early reports blamed Open VSX; Cursor and OpenSourceMalware say Open VSX, the Microsoft Marketplace and npm builds are clean, though StepSecurity still describes Open VSX distribution.

Drupal Commerce Core CVE-2026-118539: unauthenticated access bypass, exploited in the wild

The Drupal security team rates it highly critical: a missing authorization check on certain routes and entity fields lets unauthenticated attackers bypass access controls in ways that "may financially impact the vendor". Affects Commerce Core up to 2.41 and 3.0.0 to 3.3.13; the module runs on more than 42,000 sites. Drupal tells admins to upgrade immediately and audit orders for inconsistencies. Attack details have not been disclosed. Not yet on CISA KEV. Drupal's advisory was not opened directly; details via BleepingComputer and SecurityWeek.
