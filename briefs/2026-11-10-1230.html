Barracuda ESG authorization bypass plus command injection now exploited for root

Barracuda updated its advisory on Monday evening to say the two Email Security Gateway flaws it patched a week ago, CVE-2026-116606 (authentication weakness that lets an attacker change the appliance's global configuration) and CVE-2026-111560 (unauthenticated OS command injection running as root), are being exploited against "a small number of organizations". Chained, they give root on the device. Exploitation needs access to the Admin UI. Barracuda says to apply the patch manually if auto-patching did not, and to keep auto-patching on. Takeaway: ESG was the UNC4841 espionage target in 2023, so confirm the patch landed, restrict the admin interface to internal networks, and check exposed boxes for config changes.

SAP Patch Day: four CVSS 10.0 flaws in NetWeaver and Web Dispatcher, no login needed

SAP's November bulletin fixes four unauthenticated flaws rated 10.0: CVE-2026-120017 in the SAML 2.0 service provider can let an attacker log in as any user, including privileged ones, on some SAML single sign-on setups; CVE-2026-76964 (ICM) and CVE-2026-89126 (Web Dispatcher) are WebSocket memory corruption bugs that can lead to code execution; CVE-2026-89103 is an over-privileged default SAP Gateway access list that lets an outsider pose as one of the system's own servers. No exploitation reported yet. RedRays advises updating the kernel and all Web Dispatchers together to cover all 17 kernel and Web Dispatcher fixes this month. Takeaway: internet-facing Web Dispatchers are the front door, so treat these as emergency patches.

Turla's new "Cereal" toolkit hides inside Exchange to steal government email on NATO and EU

ESET documented a modular .NET toolset used by Russia's FSB-linked Turla on Microsoft Exchange servers at a government body in Kazakhstan and a Romanian government agency compromised on 23 December 2025. The CerealBox component injects into Exchange's EdgeTransport.exe and hijacks existing transport agents, so it reads mail without registering a new agent or disrupting delivery, and selectively keeps messages with DOC, DOCX and PDF attachments matching sender, recipient and subject filters. CerealNeuron listens for encrypted commands on paths that look like normal Exchange services. In Romania it targeted correspondence with NATO and EU contacts. Takeaway: on-prem Exchange at government and defence-adjacent bodies should be hunted with ESET's IOCs, since standard transport-agent checks will not show it.

AI/Cloud

Fireworks AI hit again: attackers pivot from a breached cloud provider to its dev machines

AI inference platform Fireworks says a third-party cloud provider hosting its R&D machines was breached on 23 October, and on 24 October the intruder used that to reach Fireworks development machines and run an unauthorized workload. Exposed data includes customer resource metadata, billing details (addresses, invoices, balances, credit usage) and incomplete model weights and datasets for some customers; no card numbers, which it does not store. This follows an early-October incident where environment variables with API keys were taken, which Fireworks tied to a financially motivated LLMjacking group. The cloud provider is not named. Takeaway: Fireworks customers should rotate keys again and assume partial model and dataset exposure.
