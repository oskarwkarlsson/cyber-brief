Vulns

Exploit attempts hit Oracle E-Business Suite CVE-2026-101767 (CVSS 9.8) a week after the October CPU

Defused says its EBS decoys logged exploratory exploits on Oct 27 against this unauthenticated SQL injection in the Application Object Library, which Oracle says can lead to remote code execution and full takeover of that component. Horizon3.ai reported the bug. There are no other reports of in-the-wild use yet, so this is single-source and at the probing stage, but EBS is a favourite target (Cl0p's mass EBS campaign last year). Apply the October CPU to internet-facing EBS now.

Tailscale 1.104.4 fixes the Tailworm SSH flaws that could reach root-only sockets

The release (published Oct 28, 01:05 UTC) fixes a race in Tailscale SSH socket forwarding: the daemon checked a Unix socket path, then acted as root, so an attacker could swap the path. The researcher got a root shell via the Docker socket; Tailscale says the reach is root-only sockets such as Docker or the tailscaled local API. The attacker must already control a device the policy lets SSH in with forwarding allowed. Forwarding now runs as the logged-in user. Only Linux and open-source macOS SSH servers are affected. Update servers running Tailscale SSH.

AI/Cloud

Anthropic says an unreleased model found and chained bugs into working exploits for Chrome, Safari, Android, Windows and Linux

In an Oct 27 Frontier Red Team post, Anthropic describes five chains built in the lab with "little human involvement": one-click Chrome RCE outside the sandbox on macOS, a one-click Safari chain reading data from other signed-in sites, an Android lock screen bypass over USB, a remote Windows HTTP/3 denial of service, and zero-click Linux RCE. All were reported under coordinated disclosure and are patched; none were seen in real attacks. The capability claim rests on Anthropic's own account. The takeaway for defenders: multi-bug exploit chains are getting cheaper, so patch latency matters more.

Incidents

GMO breach update: a broker links unauthorized trades to leaked logins, the leak site is down, and GMO posts a $1M bounty

GMO says the attackers' leak site and its mirrors had their domain suspended around 04:00 JST on Oct 28, and it will act against any new site. Per The Hacker News, a broker has tied unauthorized trades on some customers' accounts to logins leaked from Onamae.com Desktop Cloud, which hosts Windows desktops for FX trading. GMO's new GMO Cybercrime Bounty pays up to $1M in total for tips leading to an arrest or an international wanted notice, open until Oct 27, 2027. Customers should change broker and trading credentials used on the service.
