Barracuda breached by an ARTEX-powered intrusion: ~10 cloud accounts in ~44 hours, Kubernetes backdoor left behind

Barracuda says an attacker used an exposed valid cloud access key on 1 to 2 November, mapped its reach, then reused secrets it found to reach more systems: secret stores, configs, Kubernetes service accounts and metadata services, plus wallet hunting (Ethereum keystores, seed phrases) on servers where it got a shell. It left a backdoor in a Kubernetes cluster. Barracuda says probe names, indicators and working order match ARTEX and likens it to the Railway intrusion; it has not attributed the attack. Takeaway: hunt for long-lived cloud keys in code and artifacts, and audit Kubernetes clusters for unknown workloads.

AI/Cloud

Google GTIG: AI agents now reverse-engineer patches into n-day exploits; CAIRN seen against US aerospace

GTIG and Mandiant's quarterly AI threat tracker says adversaries have moved to autonomous multi-agent frameworks (ARTEX, CAIRN, PentAGI seen in the wild; CyberStrikeAI and HexStrike AI in experiments) and use LLM pipelines to diff patches and weaponize n-days, citing the September PaperCut NG/MF flaws. It also flags LLMjacking access resold via "LLM mixer" proxies, the Chinese PhaaS Jieyou adding an LLM chatbot for building phishing panels, and spies manipulating AI coding assistant configs to drop backdoors. Takeaway: assume the patch-to-exploit window is now days or less for internet-facing software.

Danfoss AK-SM800A fridge controllers: six pre-auth root RCE zero-days, no patch, Strict mode does not fully help

Midnight Blue found six pre-authentication stack overflows in all firmware up to 5.3.2 (five in the root-run web app, one in the Strict-mode session gateway), no CVEs yet, and says the new 5.4.0 does not fix them. No secure boot, so implants could survive reset. Belgium's CCB, Ireland's NCSC and Germany's BSI told operators to pull management interfaces off the internet; BSI has no information on exploitation of these six, and no one links them to the French and European defrost attacks. Takeaway: same playbook as this morning's Copeland alert: VPN only, check setpoints and accounts.

Telegram's new HTML widgets: RCE demos, suspected WebRAT infections, feature switched off server-side

Days after Bot API 10.4 (9 November) let bots send JavaScript widgets run in QuickJS, V12 showed code execution on Android and then Windows. Kaspersky says it saw visits to certain Telegram channels silently run PowerShell that fetched WebRAT (Salat Stealer, steals wallets and Telegram accounts) on the night of 12 to 13 November and suspects, without proof, the widget flaw. Telegram patched Android and blocked bots from sending new widgets; Durov says no one could be hacked just by receiving a message. Takeaway: update all Telegram clients, do not open widgets or start unknown bots, alert on Telegram.exe spawning powershell.exe. Link to the flaw unconfirmed.
