Storm-3358 adopts ARTEX agents against the financial sector

Microsoft Threat Intelligence says the financially motivated, Cambodia-based cluster Storm-3358 began using the agentic AI offensive framework ARTEX in October 2026, mainly against financial organizations in Southeast Asia plus a smaller number of large financial firms globally. ARTEX agents, alongside conventional automated tools, scan internet-facing systems, exploit flaws such as anonymous file upload and SSRF, and pull open-source RATs (WISP, vshell, AdaptixC2) with netcat and curl for persistence and lateral movement. Microsoft published IOCs (WISP C2 and ARTEX server IPs, active as of Nov 6), Defender detections and hunting queries, and recommends honeypots, tarpits and "fake wins" to divert autonomous agents. This is a new named actor on ARTEX after the earlier nation-state and secret-hunting reports. Takeaway: if you are in finance, sweep the IOCs, watch for machine-speed bursts of scanning and retries with default tool user agents, and harden file-upload and SSRF-prone web apps.
