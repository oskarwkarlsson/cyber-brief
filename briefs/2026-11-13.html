Vulns

N-central "4EverAble2Shell" is exploited in the wild, including on Hotfix 2, and there is still no fix

Researcher Sean Bales published 4EverAble2Shell (unauthenticated root on the server, chaining Apache Axis CVE-2026-90436 with a local escalation) and Agent2Shell (SYSTEM on managed Windows agents if the appliance ID is known), both working on 2026.4.1.26, the HF2 release N-able shipped on 10 Nov. Huntback saw full-chain attacks install XMRig and counted 21 live N-central servers mining Monero, 19 of them on HF2 and one in Sweden; Previdian also saw full-chain attempts. Exploitation needs the non-default Legacy API. N-able says hosted N-central shows scanning but no compromise, has disabled the Intune integration and restricted other features as a precaution, and says further fixes are in development. Takeaway: on-prem owners should confirm Legacy API is off, keep servers off the internet, and treat any hit as root on a box that controls customer endpoints.

Vulns

"SignDrop": unpatched Windows zero-day with public exploit gives SYSTEM and can blind antivirus

Abdelhamid Naceri (Nightmare Eclipse) released a proof-of-concept that abuses the CLFS authentication mitigation Microsoft added in October 2025: forcing a privileged process such as Defender to open a log file creates the ".cnpf" file with SYSTEM rights, and the same trick can pass antimalware tamper protection. Tested on Windows 11 26H2 and Windows Server 2025; the researcher's own estimate is that 80% of installs are exposed (registry value CLFS\Authentication\Mode 0 or 1). No Microsoft fix or statement yet and no reported in-the-wild use, but the code is public. Takeaway: a post-compromise accelerant; hunt for unexpected .cnpf file creation and watch for Microsoft guidance.

Vectors

"wfx": 4,800+ hijacked GitHub accounts push a CI secret stealer into thousands of repos, with cloud backdoors that survive rotation

Aikido first reported it; SafeDep counted 8,093 public repos with malicious commits from Tue 10 Nov, after about 61,800 probe pull requests from a wfx-docs branch. The stealer is injected into workflows or npm postinstall hooks, exfiltrates every secret, variable and OIDC token, and the commit is reverted within minutes with logs deleted. Aikido now counts 1,835 repos with exfiltrated secrets and describes persistence: AWS trust policies opened to any account and wfx-ci- federated credentials on Azure AD apps. StepSecurity traced 173 probe PRs to Fly.io GitHub app tokens, with no sign Fly.io was breached. How the tokens were stolen is unknown. Takeaway: search for wfx-docs branches and PRs since Tuesday; if hit, revoke the author's tokens, rotate every repo secret and audit cloud trust policies and federated credentials.

Crypto

US moves to seize $1.2 billion of the Binance theft and disrupts North Korea's "FaceStealer" fake-meeting scheme

The Justice Department got court authorization to seize or restrain more than $1.2 billion of the $6.3 billion Binance theft it attributes with the FBI to TraderTraitor; about $2.7 billion has been frozen in total. The FBI also took down cloud infrastructure behind FaceStealer, which it says stole over $400 million in 18 months: Calendly invites from hijacked accounts lead to fake Zoom or Teams calls with pre-recorded videos of earlier victims, then an audio "fix" installs a cookie stealer, keylogger and backdoor. It ties FaceStealer to APT38 and says it targets crypto staff and npm and Rust maintainers; whether it was used against Binance is unclear. Elliptic says the launderers have used 20,000+ wallets on 16 chains and about $3.0 billion still sits in linked addresses. Takeaway: any "install this to fix your audio" prompt in a meeting is an attack, even from a known contact.
