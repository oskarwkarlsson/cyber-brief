Mitel MiCollab zero-days hit KEV

CISA added five Mitel MiCollab flaws in the Audio, Web and Video Conferencing component to KEV on Nov 25 (CVE-2026-133323 command injection, CVE-2026-133275 file upload, CVE-2026-133303 XML injection, CVE-2026-133324 auth bypass, CVE-2026-133311 weak auth), all unauthenticated, from Mitel advisory MISA-2026-0012. Accenture APEX Labs assesses with high confidence they were exploited before Mitel's Nov 16 patch: at one victim the attacker reached root in 30 minutes and used MiCollab's stored LDAP credentials to log on to a domain controller in 32, likely with AI-assisted tooling. A second server has talked to the same actor server since Nov 9. Takeaway: patch, then hunt for prior compromise with Accenture's indicators.

1Password breached via employee GitHub

1Password says an attacker hijacked an employee's corporate GitHub account, accessed private repos and injected code into backend services that downloaded customer account records for a small number of users: names, emails, account IDs, sign-in timestamps, public keys, SRP parameters and invitation, provisioning and recovery tokens. Source code was stolen and the CI/CD environment accessed. Vaults and their keys were not compromised and it found no account takeovers; verification codes are now 10 alphanumeric characters instead of 6 digits. Takeaway: expect 1Password-themed phishing; never hand over a Secret Key or recovery code.

Fragnesia now exploited on PAN-OS

Palo Alto Networks confirmed exploitation of the Linux kernel Fragnesia bug (CVE-2026-46300, local root) against PAN-OS firewalls whose management interface is exposed to the internet, chained with the PHP2Shell flaws (CVE-2026-109618, CVE-2026-109619) as CISA warned on Oct 28. PAN-OS fixes landed Nov 24; this moves it from patched to exploited on firewalls. Palo Alto gave no technical detail of the chain. Takeaway: update PAN-OS and take management interfaces off the internet.

Actors

State hackers adopt Artex AI tool

Microsoft says Storm-0940, Storm-3358, Onyx Sleet, Pearl Sleet, Crystal Typhoon and Salt Typhoon are abusing Artex for reconnaissance, credential attacks and web app exploitation, moving from recon to privileged access in minutes. Artex uses existing pentest techniques, and actors vary IPs and user agents, so Microsoft says the durable signal is behavioral: bursts of varied requests and retries at machine speed from one source. Separately, Italy's CSIRT and Switzerland's NCSC warned of autonomous AI agent campaigns (Artex, CyberStrikeAI, DeepSeek Harness, PentAGI), with Switzerland reporting its first successful AI-assisted attacks.
