Vulns

Juniper Session Smart Router bug now exploited

CISA added CVE-2026-103406 to its Known Exploited Vulnerabilities catalog on Nov 25: an OS command injection in HPE Juniper Session Smart Conductor and Session Smart Router that lets a remote attacker run commands as root via a crafted salt minion ID. Juniper fixed it in its October 2026 out-of-cycle bulletin covering internally found SSR flaws. Federal agencies have until Nov 28 and CISA flags it for forensic triage; ransomware use is listed as unknown. No public detail yet on who is exploiting it. Takeaway: if you run SSR or Conductor, confirm you are on the October fixed releases and check for compromise.

Attackers probe GeoServer RCE chain bugs

watchTowr sees exploit probes for CVE-2026-120705 (unauthenticated XML injection for file reads and SSRF) and CVE-2026-129243 (access control bypass to admin operations), two of five bugs Rapid7's Jonah Burgess chained for unauthenticated RCE and published this week with PoC code. Eye Security separately showed RCE on Linux and Windows and counts 3,000+ exposed instances. So far only error-based probes to confirm vulnerable servers, no confirmed RCE. Takeaway: upgrade to GeoServer 3.0.2, 2.28.6 or 2.27.7; it is widely used by governments and utilities.

Ransomware hits Guadeloupe university hospital

France's ANSSI is investigating a suspected ransomware attack that encrypted databases at the University Hospital of Guadeloupe from Saturday evening. Surgeries, consultations and imaging are cancelled through at least Friday, radiation therapy is suspended and chemotherapy sessions were cancelled; emergency, dialysis and urgent cardiac care continue on pen and paper. ANSSI is examining entry via an IT supplier reportedly compromised months ago. No ransom demand received, no claim, data theft unknown; prosecutors have opened a criminal case.

Vectors

Fake .NET job tests deliver NuGet malware

Socket found 13 malicious NuGet packages used in fake "Home Assessment" coding tests aimed at Windows .NET developers, mostly posing as WinUI 3 and WPF button controls. Building or running the project downloads files from GitHub, stages a DLL side-loading pair around osk.exe, or runs an executable, leading to browser credential theft and remote access. The newest lure repo, "Mini File Vault & Tracker", was created Nov 4. Takeaway: treat recruiter-supplied projects as untrusted and build them only in a throwaway VM.
